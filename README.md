# Primeira API

Educational REST API for managing people, levels, classes, and enrollments.

**Category:** REST API

**Stack:** JavaScript, Node.js, Express, Sequelize, MySQL

**Status:** Portfolio-ready educational project

## Run Locally

```bash
cd aula_20_04_2022
node api/index.js
```
